# Sirus.AI
Sirus is a Python-based AI assistant powered by the Gemini API, built to explore agentic AI capabilities through intelligent and interactive conversations.

##  Overview

Sirus enables users to interact through both text and voice, creating a seamless conversational experience. The project serves as an exploration of AI assistants, speech interfaces, and the foundations of agentic systems.

##  Features

*  Intelligent conversations powered by Gemini
*  Speech-to-Text voice input
*  Natural Text-to-Speech responses
*  Dual interaction modes (Voice & Text)
*  Dynamic greetings based on time of day
*  Fast and lightweight terminal-based interface
*  Environment-based API key management

## How It Works

1. User speaks or types a query.
2. Sirus processes the input.
3. Gemini generates an intelligent response.
4. Sirus delivers the response via text or voice.

##  Tech Stack

* Python
* Gemini API
* SpeechRecognition
* Pyttsx3
* Python Dotenv

##  Installation

```bash
git clone https://github.com/Shivam-0978/sirus.git
cd sirus
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

Run the assistant:

```bash
python main.py
```
